# Карьера АРКА

Статический лендинг. Открой **`index.html`**.

```
index.html          главная
assets/             фото и favicon
robots.txt          поиск + ИИ-боты
sitemap.xml         карта сайта
llms.txt            кратко для ИИ
llms-full.txt       полный текст для ИИ
site.webmanifest
AGENTS.md           git, домен, правила правок
legacy/             старый React-шаблон, не деплоить
```

Не коммить `.env`. `node_modules` уже не в корне.
